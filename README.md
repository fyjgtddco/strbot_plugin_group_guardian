# 🛡️ AstrBot 智能群管插件 (GroupGuardian)

AI 驱动的群管理插件，支持自动冲突检测、刷屏检测、手动禁言踢人等。

## ✨ 功能

### 🤖 AI 自动管理
- **冲突检测**：自动识别群内吵架/冲突，AI 评估严重等级
- **智能警告**：冲突时自动 @ 双方发出警告
- **升级禁言**：警告后继续冲突自动禁言
- **刷屏检测**：自动识别并禁言刷屏用户

### 👮 手动管理指令

| 指令 | 说明 | 权限 |
|------|------|------|
| `/禁言 @xxx 60` | 禁言60秒 | 管理员 |
| `/解禁 @xxx` | 解除禁言 | 管理员 |
| `/踢人 @xxx` | 踢出群聊 | 管理员 |
| `/全体禁言` | 切换全体禁言 | 管理员 |
| `/群管白名单 add @xxx` | 添加白名单 | 管理员 |
| `/群管白名单 del @xxx` | 删除白名单 | 管理员 |
| `/群管白名单 list` | 查看白名单 | 管理员 |
| `/群管状态` | 查看运行状态 | 所有人 |
| `/群管设置` | 查看当前设置 | 所有人 |
| `/群管帮助` | 查看帮助 | 所有人 |

## ⚙️ 配置说明

在 AstrBot 配置面板中设置以下参数：

### 一、管理员权限
- `admin_qq`: 管理员QQ号（逗号分隔）
- `whitelist_qq`: 白名单QQ号（逗号分隔，免除所有管理操作）

### 二、AI 智能分析
- `ai_conflict_detection`: 是否启用AI冲突检测
- `ai_auto_warn`: 是否主动警告
- `ai_auto_mute_after_warn`: 警告后继续吵架是否自动禁言
- `ai_mute_duration`: 自动禁言时长（秒）
- `ai_model`: AI模型名称（为空则使用默认）

### 三、刷屏检测
- `flood_detection`: 是否启用刷屏检测
- `flood_threshold`: 时间窗口（秒）
- `flood_max_msgs`: 窗口内最大消息数
- `flood_mute_duration`: 刷屏禁言时长（秒）
