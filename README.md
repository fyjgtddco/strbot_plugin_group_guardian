# 🛡️ AstrBot 智能群管插件

AI 驱动的群管理插件，支持冲突检测、刷屏检测、手动禁言踢人等。

## 指令

| 指令 | 说明 | 权限 |
|------|------|------|
| `/禁言 @xxx 60` | 禁言60秒 | 管理员 |
| `/解禁 @xxx` | 解除禁言 | 管理员 |
| `/踢人 @xxx` | 踢出群聊 | 管理员 |
| `/全体禁言` | 切换全体禁言 | 管理员 |
| `/群管白名单 add/del/list` | 白名单管理 | 管理员 |
| `/群管状态` | 查看状态 | 所有人 |
| `/群管帮助` | 帮助信息 | 所有人 |

## 配置

在 Web 管理面板插件设置中配置管理员QQ、白名单、AI开关等。

## 安装

放入 `data/plugins/`，删除 `__pycache__`，重启即可。
